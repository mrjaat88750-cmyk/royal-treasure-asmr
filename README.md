# Royal Treasure – ASMR Puzzle V2

Native Android Kotlin / Jetpack Compose starter project. Configuration: JDK 17, Gradle 8.9, Android Gradle Plugin 8.7.3, Kotlin 2.0.21, compileSdk 35.

## Included
- Animated splash progress screen.
- Home screen with 2-column x 3-row level cards, six pages and 34 named level entries.
- Settings, Unlock All, Collection, No Ads placeholder, countdown pill, mode selector and banner-ad placeholder.
- Canvas-drawn royal emblems, ribbon banners, gold trims and vector puzzle pieces; no external image assets required.
- Drag pieces from horizontal tray onto numbered target outlines; correct/wrong drop feedback.
- Two-stage sample puzzles, five-minute timer, 5-error limit, retry dialog and boosters.
- Settings modal with Music/SFX sliders, Unlock modal, 3x3 Collection grid with 23-page pagination.
- Basic coin and unlock persistence using SharedPreferences.

## Build on a phone
1. Extract the ZIP in Termux.
2. Create an empty GitHub repository.
3. Push this project using the commands in `TERMUX_GUIDE_HI.txt`.
4. Open GitHub > Actions > Build Royal Treasure V2 > Run workflow.
5. Download artifact `Royal-Treasure-V2-APK-AAB` after the run succeeds.

## Honest prototype limitations
- This is source code, not a verified APK. A successful remote build and real-device QA have not yet been performed.
- Procedural vector illustrations are starter artwork, not finished hand-painted art.
- Six level definitions are playable examples; the 34-entry home catalog needs additional authored puzzle data for 34 unique playable levels.
- Rewarded ads, No Ads purchase, and full background music are UI placeholders, not connected services.
- The AAB generated by the workflow is unsigned. Configure protected release signing and Play App Signing before publishing.
